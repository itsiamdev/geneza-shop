# Geneza Shop

Landing page for Geneza, a local store in Târgu Neamț, Romania.

## Description

The page presents the store's identity, product categories, weekly offers, brand story, and a newsletter subscription area.

## Live Demo

[View the live website](https://itsiamdev.github.io/geneza-shop/)

## Technologies

- Semantic HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: DM Sans and Playfair Display

## Project Structure

```text
.
├── index.html   # Page structure and mobile menu interaction
├── style.css    # Styles, layout, and responsive design
└── README.md    # Project documentation
```

## Local Setup

No dependencies or installation are required.

1. Open `index.html` in a browser; or
2. Open the folder in VS Code and use an extension such as Live Server.

The page uses Google Fonts, so an internet connection is required to load the fonts.

## Included Sections

- Hero section with the main message and weekly offer
- Product categories
- Geneza offers
- Store story
- Local section for Târgu Neamț
- Newsletter form
- Footer with navigation and social links

## Current Status

This project is a front-end prototype. The newsletter form is not connected to an external service, and some footer links are still placeholders that need to be replaced with their real destinations.
